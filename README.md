# Sai Poojitha — Portfolio

Personal portfolio built with Next.js, Tailwind CSS and content-collections, deployed on Vercel.

- `npm run dev` — local dev server
- `npm test` — content and logic tests (Node's built-in test runner)
- `npm run build` — production build

Home-page copy lives in `src/data/content.ts`; profile, socials and hackathons in `src/data/resume.tsx`; blog posts in `content/`.

Layout inspired by [Brittany Chiang's v4](https://v4.brittanychiang.com).
